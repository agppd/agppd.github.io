## 常见的基础类型

### 1. 标准内置类型

| 类型 | 标准最低字节数 | 常见平台字节数（64位） | 说明 |
|------|----------------|------------------------|------|
| `int` | 2 | 4 | 基本整型，通常为处理器最自然的整数宽度 |
| `long` | 4 | Windows: 4；Linux/macOS: 8 | 宽度随平台变化|
| `char` | 1 | 1 | 占用 1 字节，用于存储字符或底层字节数据 |
| `float` | 4（通常） | 4 | 单精度浮点数（IEEE-754 binary32） |
| `double` | 8（通常） | 8 | 双精度浮点数（IEEE-754 binary64） |

> `char` 的有符号性由编译器决定，若需明确指定，应使用 `signed char` 或 `unsigned char`。

**这个世界上，在这个C标准里，没有long long这种东西！！！**

### 2. 其他重要的内置类型


| 类型 | 常见字节数 | 用途说明 |
|------|------------|----------|
| `short` | 2 | 短整型，用于内存敏感场景下的较小整数 |
| `bool` | 1 | 布尔类型，取值 `true`（转换为 1）或 `false`（转换为 0） |
| 无符号变体（如 `unsigned int`） | 同对应有符号类型 | 表示非负整数，可扩大正数表示范围（最高位不再用于符号） |

### 4. 定义变量

#### 标识符

现在：理解为变量名即可

- 只能由字母（a～z，A～Z）、数字 （0～9）、下划线（_）组成，并且第一个字符必须是字母或下划线，不能以数字开头。

- C语言不限制标识符的长度

#### 定义

```c
int a; /*定义一个整形变量a，初始化由系统进行处理*/
double b; 

int c = 123; /*定义一个c，初始化为123*/
```

#### 只读变量

C 语言允许使用 `const` 修饰符定义**只读变量**（**不是常量**）

```c
const int root = 1;
const double exp = 0.001
```

只读变量必须初始化，下面就是典型例子

```c
const int x; /*错误，没有进行初始化*/
```
**这个世界上，在这个C标准里，常量只能是数字，不存在字母！！！**

## 算术运算

### 1. 算术运算符

| 运算符 | 功能 | 说明 |
|--------|------|------|
| `+` | 加法 / 一元正号 | 二元或一元运算 |
| `-` | 减法 / 一元负号 | 二元或一元运算 |
| `*` | 乘法 | 二元运算 |
| `/` | 除法 | 详见下方第 2 条 |
| `%` | 取模（求余） | **仅限整数操作数** |

### 2. 除法 `/` 与取模 `%`

#### 1. 整数除法与浮点数除法

- 若两个操作数均为整数类型，执行整数除法，结果截断为整数（舍弃小数部分）。  
- 若任一操作数为 `float` 或 `double`，执行浮点数除法。

```c
int a = 5 / 2;      /* 结果为 2 */
double b = 5.0 / 2; /* 结果为 2.5 */
```

#### 2. 负数除法

当 `/` 或 `%` 的操作数中存在负数时，结果的**符号或舍入方向由具体编译器实现定义**。例如表达式 `-7 / 3`，不同编译器可能给出 `-2`（向零取整）或 `-3`（向负无穷取整）两种结果。

```c
int x = -7 / 3; /*结果可能为 -2 或 -3，取决于编译器*/
int y = -7 % 3; /*符号随之变化，与上述除法保持一致*/
```

### 3. 自增 `++` 与自减 `--` 

| 形式 | 术语 | 效果 |
|------|------|------|
| `a++` | 后缀自增 | 先取 `a` 的当前值作为表达式结果，再将 `a` 加 1 |
| `++a` | 前缀自增 | 先将 `a` 加 1，再将新值作为表达式结果 |
| `a--` | 后缀自减 | 先取 `a` 的当前值作为表达式结果，再将 `a` 减 1 |
| `--a` | 前缀自减 | 先将 `a` 减 1，再将新值作为表达式结果 |

```c
int x = 5;
int y = x++; /*y= 5, x = 6*/
int z = ++x; /*x = 7, z = 7*/
```

### 4. 复合赋值运算符

C 提供了以下简写形式，其等价展开如下：

| 运算符 | 等价形式 |
|--------|----------|
| `a += b` | `a = a + b` |
| `a -= b` | `a = a - b` |
| `a *= b` | `a = a * b` |
| `a /= b` | `a = a / b` |
| `a %= b` | `a = a % b` |

### 5. 类型转换

#### 1. 隐式类型转换

C 遵循“通常算术转换”规则：
- 整型提升（Integral Promotion）：`char`、`short` 等小整数类型在参与算术运算前被自动提升为 `int`。
- 若两操作数类型不同，**表示范围较小**的类型自动转换为**表示范围较大**的类型（例如 `int` 转换为 `double`）。

#### 2. 显式强制类型转换

语法为 `(类型名) 表达式`，用于人为指定转换目标。

```c
int a = 5;
int b = 2;
double result = (double)a / b;  /*将 a 转为 double，结果为 2.5*/
```

### 6. 运算符优先级与结合性（简表）

以下为常用运算符的优先级顺序（由高至低）：

1. `()`（括号）—— 最高
2. `++`（后缀）、`--`（后缀）
3. `++`（前缀）、`--`（前缀）、`+`（一元）、`-`（一元）
4. `*`、`/`、`%`
5. `+`、`-`（二元）
6. `=` 及复合赋值（`+=`、`-=` 等）—— 最低

> 总之，你全都加`()`就得了

### 7. 变量声明的位置限制

**C 要求所有局部变量声明必须位于函数（`{ ... }`）的开头，且在第一条执行语句之前**。

```c
int main(void)
{
    int a;          /* 声明必须放在最前面 */
    double b;
    
    a = 10;         /* 执行语句 */
    b = a / 2.0;
}
```
