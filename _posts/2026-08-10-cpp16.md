## 1. 模板（Template）

模板是 C++ 支持**编译期泛型编程**的核心，允许定义与类型无关的函数或类，在编译时由编译器根据实际使用类型生成具体代码。

### 1.1 函数模板

**定义**：使用 `template <typename T>` 或 `template <class T>` 前置声明，后跟函数定义，其中 `T` 为类型参数。

```cpp
#include <iostream>
using namespace std;

// 函数模板：交换两个任意类型的值
template <typename T>
void swapValues(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3, y = 4;
    swapValues(x, y);   // 编译器生成 swapValues<int>
    cout << x << ", " << y << endl; // 4, 3

    double p = 1.2, q = 3.4;
    swapValues(p, q);   // 生成 swapValues<double>
    cout << p << ", " << q << endl; // 3.4, 1.2

    // 也可以显式指定类型
    swapValues<string>(string("hello"), string("world"));
    return 0;
}
```

**客观规则**：
- 编译器通过**实参推导**自动确定模板参数，也可显式指定。
- 模板代码仅在**被调用时**才会实例化（生成对应类型的函数代码），不会增加未使用类型的二进制大小。
- 模板定义通常放在头文件中（因为实例化需要完整定义）。

### 1.2 类模板

**定义**：与函数模板类似，类名前加 `template <typename T>`。

```cpp
template <typename T>
class Stack {
private:
    T* data;
    int capacity;
    int top;
public:
    Stack(int cap = 10) : capacity(cap), top(-1) {
        data = new T[capacity];
    }
    ~Stack() { delete[] data; }
    void push(const T& val) {
        if (top >= capacity - 1) return;
        data[++top] = val;
    }
    bool pop(T& out) {
        if (top < 0) return false;
        out = data[top--];
        return true;
    }
    bool empty() const { return top == -1; }
};

int main() {
    Stack<int> intStack(5);    // 实例化 Stack<int>
    intStack.push(10);
    int val;
    intStack.pop(val);
    cout << val << endl;       // 10

    Stack<string> strStack(3);
    strStack.push("hello");
    string s;
    strStack.pop(s);
    cout << s << endl;         // hello
    return 0;
}
```

**注意**：类模板的成员函数若在类外定义，必须使用模板参数声明，例如：
```cpp
template <typename T>
void Stack<T>::push(const T& val) { /* ... */ }
```

### 1.3 模板与多态的关系
- **运行时多态（虚函数）**：绑定发生在运行时，通过 VTable 动态跳转，适用于接口统一但行为不同的场景。
- **编译期多态（模板）**：绑定发生在编译期，生成多个函数/类副本，适用于性能敏感且类型已知的场景（如容器）。两者不互斥，可混合使用。

## 2. STL（Standard Template Library）

STL 是 C++ 标准库的核心部分，由 **容器（Containers）**、**迭代器（Iterators）**、**算法（Algorithms）** 和 **函数对象（Functors）** 四大组件构成，全部基于模板实现。

### 2.1 容器

STL 提供了多种数据结构，常见的有：

| 容器 | 特性 | 底层实现 | 头文件 |
|------|------|----------|--------|
| `vector<T>` | 动态数组，随机访问快，尾部增删快 | 连续内存 | `<vector>` |
| `list<T>` | 双向链表，任意位置插入删除快，不支持随机访问 | 双向链表 | `<list>` |
| `deque<T>` | 双端队列，两端增删快，支持随机访问 | 分段连续空间 | `<deque>` |
| `set<T>` / `multiset<T>` | 有序集合（不允许/允许重复），基于红黑树 | 平衡二叉搜索树 | `<set>` |
| `map<K,V>` / `multimap<K,V>` | 键值对映射，按键有序 | 红黑树 | `<map>` |
| `unordered_set` / `unordered_map` | 哈希表实现的无序容器（C++11） | 哈希表 | `<unordered_set>` / `<unordered_map>` |

**示例：vector 的使用**
```cpp
#include <vector>
#include <iostream>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3, 4, 5}; // C++11 初始化列表
    v.push_back(6);                  // 尾部添加
    v.pop_back();                    // 尾部删除

    // 随机访问
    cout << v[2] << endl;            // 3

    // 遍历（使用范围 for 循环）
    for (int x : v) {
        cout << x << " ";
    }
    cout << endl;

    // 获取大小和容量
    cout << "size: " << v.size() << ", capacity: " << v.capacity() << endl;
    return 0;
}
```

### 2.2 迭代器

迭代器是容器与算法之间的桥梁，是一种泛型指针，提供统一方式遍历容器中的元素。

| 迭代器类型 | 能力 | 对应容器 |
|-----------|------|----------|
| 输入/输出迭代器 | 单向读/写 | `istream_iterator`, `ostream_iterator` |
| 前向迭代器 | 单向读写，可多次遍历 | `forward_list`, `unordered_set` |
| 双向迭代器 | 前向 + 后向 | `list`, `set`, `map` |
| 随机访问迭代器 | 支持 `+n`, `-n`, `[]` | `vector`, `deque`, `array` |

**示例**：使用迭代器遍历并修改元素
```cpp
#include <vector>
#include <iostream>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3, 4};
    // 获取 begin/end 迭代器
    for (auto it = v.begin(); it != v.end(); ++it) {
        *it *= 2;   // 修改每个元素
    }
    // 使用 const_iterator 只读
    for (auto it = v.cbegin(); it != v.cend(); ++it) {
        cout << *it << " ";  // 2 4 6 8
    }
    return 0;
}
```

### 2.3 算法

STL 提供了大量通用算法，如排序、查找、变换等，均作用于迭代器范围。

**常用算法**：`sort`、`find`、`binary_search`、`for_each`、`transform`、`copy` 等（头文件 `<algorithm>`）。

```cpp
#include <algorithm>
#include <vector>
#include <iostream>
using namespace std;

int main() {
    vector<int> v = {5, 2, 8, 1, 9};
    sort(v.begin(), v.end());   // 升序排序
    // 输出: 1 2 5 8 9
    for (int x : v) cout << x << " ";

    // 查找元素 5
    auto it = find(v.begin(), v.end(), 5);
    if (it != v.end()) cout << "Found at position " << (it - v.begin()) << endl;

    // 使用 transform 将每个元素平方
    vector<int> squared(v.size());
    transform(v.begin(), v.end(), squared.begin(), [](int x) { return x * x; });
    // 输出: 1 4 25 64 81
    for (int x : squared) cout << x << " ";

    return 0;
}
```

### 2.4 函数对象（仿函数）与 Lambda 表达式（C++11）

STL 算法经常接受可调用对象（函数指针、函数对象、lambda）作为自定义操作。

- **函数对象**：重载了 `operator()` 的类对象。
- **Lambda 表达式**：匿名函数，语法 `[捕获](参数)->返回类型 { 函数体 }`。

```cpp
#include <algorithm>
#include <vector>
#include <iostream>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3, 4, 5};
    // 使用 lambda 筛选偶数
    int count = count_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; });
    cout << "Even count: " << count << endl; // 2
    return 0;
}
```

## 3. 异常处理（Exception Handling）

C 语言通常通过返回错误码（如 `-1` 或 `NULL`）和全局 `errno` 报告错误，但这要求每个调用点都检查返回值，容易遗漏且逻辑被打散。C++ 提供了**异常**机制，将错误检测与错误处理分离。

### 3.1 基本语法

- **`try` 块**：包含可能抛出异常的代码。
- **`throw` 语句**：抛出异常对象（可以是任何类型，但推荐继承自 `std::exception`）。
- **`catch` 子句**：捕获并处理特定类型的异常。

```cpp
#include <iostream>
#include <stdexcept> // std::runtime_error
using namespace std;

double divide(double numerator, double denominator) {
    if (denominator == 0.0) {
        throw runtime_error("Division by zero"); // 抛出异常对象
    }
    return numerator / denominator;
}

int main() {
    try {
        double result = divide(a, b);
        cout << "Result: " << result << endl;
    } catch (const runtime_error& e) {
        cerr << "Error: " << e.what() << endl;
    }
    return 0;
}

```

**运行示例**：
- 输入 `10 2` → 输出 `Result: 5`
- 输入 `10 0` → 输出 `Error: Division by zero`

**关键点**：
- `throw` 抛出的异常对象会被**第一个匹配的 `catch` 子句**捕获。
- `catch` 参数建议使用**常量引用**（`const exception_type&`），避免拷贝开销，且能捕获派生类异常（多态）。
- 若未捕获异常，程序会调用 `std::terminate()` 并终止。

---

### 3.2 栈展开（Stack Unwinding）

当异常抛出时，程序会**沿着调用栈向上回溯**，逐层销毁已构造的局部对象（调用析构函数），直到找到匹配的 `catch` 块。这个过程称为**栈展开**。

```cpp
class Resource {
public:
    Resource() { cout << "Acquire resource" << endl; }
    ~Resource() { cout << "Release resource" << endl; }
};

void funcB() {
    Resource r;          // 构造
    throw runtime_error("error");
    // r 的析构函数会在栈展开时被调用
}

void funcA() {
    try {
        funcB();
    } catch (const exception& e) {
        cout << "Caught: " << e.what() << endl;
    }
}
// 输出顺序：Acquire resource -> Release resource -> Caught: error
```
**客观事实**：栈展开保证了 C++ 的 RAII 机制（资源获取即初始化）在异常发生时依然有效——所有栈上对象的析构函数都会被调用，资源得到释放。

---

### 3.3 异常规范（已废弃的历史）

C++98 曾允许 `throw()` 指定函数不抛出异常，但C++11 起弃用，改用 `noexcept` 关键字。

- `void func() noexcept;` 表示该函数不会抛出异常，若实际抛出则直接调用 `std::terminate`。
- `noexcept` 可用于性能优化（编译器可省略栈展开代码），移动构造函数、析构函数等通常应标记为 `noexcept`。

---

### 3.4 标准异常类层次

C++ 标准库在 `<stdexcept>` 中定义了异常基类 `std::exception`，及其派生类：

```
std::exception
├── std::bad_alloc       (new 失败)
├── std::bad_cast        (dynamic_cast 失败)
├── std::runtime_error   (运行时错误)
│   ├── std::range_error
│   ├── std::overflow_error
│   └── std::underflow_error
└── std::logic_error     (程序逻辑错误)
    ├── std::domain_error
    ├── std::invalid_argument
    ├── std::length_error
    └── std::out_of_range
```

**建议**：自定义异常类可直接继承 `std::runtime_error` 或 `std::logic_error`，并传递字符串给基类构造函数。

```cpp
class MyError : public runtime_error {
public:
    explicit MyError(const string& msg) : runtime_error(msg) {}
};
```

### 3.5 异常安全性保证

编写异常安全代码时，函数应承诺以下等级之一（从低到高）：

| 保证等级 | 含义 |
|----------|------|
| **基本保证** | 发生异常后，程序状态不变（无资源泄漏），但可能改变值。 |
| **强保证** | 发生异常后，程序状态完全回滚至调用前（事务语义）。 |
| **无抛出保证** | 函数永远不会抛出异常（如 `noexcept`）。 |

**示例**：使用拷贝交换（Copy-and-Swap）实现强保证。
```cpp
class String {
    char* data;
public:
    void swap(String& other) noexcept {
        std::swap(data, other.data);
    }
    String& operator=(const String& other) {
        String temp(other);   // 可能抛出，但若抛出，this 未变
        swap(temp);           // 无抛出
        return *this;
    }
};
```

### 3.6 异常处理与 C 代码的互操作

- 在 C++ 中调用 C 函数时，C 函数若发生错误（返回错误码），可将其转换为异常抛出。
- 在 C 代码中无法捕获 C++ 异常，因此在 C 接口的封装层（`extern "C"`）必须捕获所有异常，将其转换为错误码返回。

```cpp
extern "C" int c_api_function() {
    try {
        // 调用 C++ 内部逻辑
        return 0; // success
    } catch (...) {
        return -1; // error
    }
}
```

### 3.7 使用异常 vs 错误码的客观权衡

| 维度 | 错误码 | 异常 |
|------|--------|------|
| **错误传播** | 手动逐层返回 | 自动栈展开，忽略中间层 |
| **代码可读性** | 大量 `if` 判断，逻辑混杂 | 主逻辑清晰，错误处理集中 |
| **性能** | 无额外开销 | 抛出时有栈展开代价（但仅在异常路径） |
| **适用范围** | 小型项目、实时系统、C 互操作 | 大型应用、库开发 |
| **安全性** | 易忽略返回值导致错误 | 强制处理（否则终止） |

**客观建议**：在 C++ 工程中，优先使用异常处理错误；在性能敏感的热路径或明确禁止异常的模块中，可限制使用。

### 3.8 综合示例：使用 STL 容器与异常处理

```cpp
#include <vector>
#include <iostream>
#include <stdexcept>
using namespace std;

int getElement(const vector<int>& vec, size_t index) {
    if (index >= vec.size()) {
        throw out_of_range("Index out of range");
    }
    return vec[index];
}

int main() {
    vector<int> data = {10, 20, 30};
    try {
        int val = getElement(data, 5); // 抛出异常
        cout << val << endl;
    } catch (const out_of_range& e) {
        cerr << "Caught out_of_range: " << e.what() << endl;
    } catch (const exception& e) {
        cerr << "Caught generic exception: " << e.what() << endl;
    }
    // 输出：Caught out_of_range: Index out of range
    return 0;
}
```

## 4. 模板、STL 与异常处理的协同

- **模板**为 STL 提供了类型安全的容器与算法基础。
- **STL** 自身在内存分配失败（`bad_alloc`）、访问越界（`at()` 方法）等场景使用异常报告错误。
- **异常处理**为模板编程提供了统一的错误报告机制，使得泛型代码无需关心具体类型的错误处理方式。

**工程实践建议**：
1. 模板类中的成员函数如需抛出异常，应在文档中明确说明。
2. STL 容器在抛出异常时，保证基本异常安全（如 `vector::push_back` 在内存分配失败时不会影响原有内容）。
3. 在自定义模板类中，合理使用 `noexcept` 标识移动构造、交换等函数，以优化性能。
