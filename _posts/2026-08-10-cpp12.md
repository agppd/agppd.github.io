## 1. 函数重载（Function Overloading）

### 1.1 定义
在 C++ 中，允许在同一作用域内定义**多个同名函数**，只要它们的**参数列表不同**（参数个数、类型或顺序不同）。返回值类型不作为区分依据。

### 1.2 与 C 的对比
- **C 语言**：不允许同名函数存在，即使参数不同也会导致符号冲突。
- **C++**：编译器对函数名进行“名字修饰”（name mangling），将函数名和参数类型编码成唯一的内部符号，从而实现重载。

### 1.3 示例
```cpp
#include <stdio.h>

// 重载函数：打印整数
void print(int x) {
    printf("int: %d\n", x);
}

// 重载函数：打印双精度浮点数
void print(double x) {
    printf("double: %f\n", x);
}

// 重载函数：打印字符串
void print(const char* s) {
    printf("string: %s\n", s);
}

int main() {
    print(10);        // 调用 print(int)
    print(3.14);      // 调用 print(double)
    print("hello");   // 调用 print(const char*)
    return 0;
}
```

### 1.4 注意事项
- **不可仅靠返回值区分**：`int foo();` 和 `double foo();` 无法同时存在，因为调用时无法确定使用哪个。
- **默认参数与重载可能产生二义性**：
  ```cpp
  void func(int a) {}
  void func(int a, int b = 0) {}  // 调用 func(1) 时二义性
  ```
- **C 函数与 C++ 重载混用**：若需要被 C 代码调用，需使用 `extern "C"` 阻止名字修饰。

## 2. 类（Class）基础

C++ 的类可以看作 C 语言结构体的“增强版”，它不仅包含数据成员，还可以包含**成员函数**（即方法），并支持**访问控制**（public/private/protected）。

### 2.1 类的定义与访问控制
```cpp
class Rectangle {
private:              // 私有成员，仅类内部可访问
    int width;
    int height;

public:               // 公有成员，外部可访问
    void setSize(int w, int h) {
        width = w;
        height = h;
    }

    int area() {
        return width * height;
    }
};
```

**与 C 结构体的区别**：
- C 结构体的成员默认是公有（可通过指针任意修改）。
- C++ 的 `class` 默认访问权限为 `private`，而 `struct` 在 C++ 中默认是 `public`，但 `struct` 也可以包含成员函数。通常用 `class` 表示封装性更强的类型。

### 2.2 对象的创建与成员访问
```cpp
int main() {
    Rectangle rect;          // 栈上分配对象
    rect.setSize(3, 4);      // 调用成员函数（. 运算符）
    int a = rect.area();     // a = 12

    Rectangle* pRect = new Rectangle();  // 堆上分配（需 delete）
    pRect->setSize(5, 6);                // 通过指针调用（->）
    int b = pRect->area();               // b = 30
    delete pRect;
    return 0;
}
```
- 对象的成员访问与结构体完全一致（`.` 和 `->`）。
- `new`/`delete` 是 C++ 的动态内存管理运算符，等效于 `malloc`/`free`，但会调用构造函数/析构函数（见下文）。

## 3. 构造函数（Constructor）

构造函数是类的一种特殊成员函数，在对象创建时自动调用，用于初始化数据成员。  
- 函数名与类名相同，**无返回值**（也不能写 `void`）。
- 可重载（支持多个参数列表不同的构造函数）。
- 若未显式定义任何构造函数，编译器会生成一个默认的无参构造函数（什么也不做）。

### 3.1 定义与使用
```cpp
class Rectangle {
private:
    int width;
    int height;
public:
    // 无参构造函数（默认）
    Rectangle() {
        width = 0;
        height = 0;
    }

    // 带参构造函数（重载）
    Rectangle(int w, int h) {
        width = w;
        height = h;
    }

    int area() { return width * height; }
};

int main() {
    Rectangle r1;            // 调用无参构造函数
    Rectangle r2(3, 4);      // 调用带参构造函数
    Rectangle r3 = {5, 6};   // C++11 聚合初始化，也可调用构造函数（需满足条件）
    return 0;
}
```

### 3.2 初始化列表（推荐写法）
在构造函数体之前，可以使用**初始化列表**直接初始化成员变量，效率更高且可初始化 const 成员或引用。
```cpp
Rectangle(int w, int h) : width(w), height(h) {}
```
初始化列表的执行顺序**按成员声明顺序**，而非列表顺序。

## 4. 析构函数（Destructor）

析构函数在对象销毁时（离开作用域或 `delete`）自动调用，用于释放资源（如动态内存、文件句柄等）。  
- 函数名为 `~类名`，**无返回值，无参数**（因此不能重载）。
- 若未显式定义，编译器自动生成一个空析构函数。

```cpp
class FileHandler {
private:
    FILE* fp;
public:
    FileHandler(const char* filename) {
        fp = fopen(filename, "r");
    }
    ~FileHandler() {
        if (fp) fclose(fp);   // 自动释放文件资源
    }
};
```

## 5. 成员函数的定义方式

成员函数可在类内直接定义（默认 `inline`），也可在类外定义（需用作用域运算符 `::`）。

```cpp
// 类内声明
class Point {
private:
    int x, y;
public:
    void set(int a, int b);
    int getX() const;   // const 成员函数（见下文）
};

// 类外定义
void Point::set(int a, int b) {
    x = a;
    y = b;
}
```

## 6. `this` 指针

在非静态成员函数内部，`this` 是一个指向当前对象的指针（`类名* const`）。  
可用于区分同名参数和成员：
```cpp
void set(int x) {
    this->x = x;   // this->x 是成员，x 是参数
}
```

## 7. `const` 成员函数

在成员函数参数列表后加 `const`，表示该函数**不会修改对象的数据成员**（除非成员被声明为 `mutable`）。  
- 该函数可以被 `const` 对象调用。
- 非 `const` 对象也可调用，但 `const` 对象不能调用非 `const` 成员函数。

```cpp
class Point {
    int x, y;
public:
    int getX() const { return x; }   // 保证不修改成员
    void move(int dx) { x += dx; }   // 非常量，会修改
};

void test(const Point& p) {
    int a = p.getX();  // 可以
    // p.move(5);      // 错误，const 对象不能调用非常量成员
}
```

## 8. `static` 成员

### 静态数据成员
- 属于类本身，而非某个对象，所有对象共享同一份数据。
- 必须在类外单独定义（分配存储空间），通常放在 `.cpp` 文件。

```cpp
class Counter {
private:
    static int count;   // 声明
public:
    Counter() { ++count; }
    ~Counter() { --count; }
    static int getCount() { return count; }  // 静态成员函数
};

int Counter::count = 0;   // 定义（必须）
```

### 静态成员函数
- 只能访问静态成员，不能访问非静态成员（因为没有 `this` 指针）。
- 可通过类名直接调用（`Counter::getCount()`），无需对象。

## 9. 访问控制总结

| 访问说明符 | 类内部 | 派生类（未介绍） | 外部 |
|------------|--------|------------------|------|
| `private`  | 可以      | 不可                | 不可    |
| `protected`| 可以      | 可以（继承后）      | 不可    |
| `public`   | 可以      | 可以                | 可以    |

本文仅涉及 `private`/`public`，`protected` 主要在继承中使用（不涉及）。

## 10. 与 C 结构体的对比总结

| 特性 | C 结构体 | C++ 类 |
|------|----------|--------|
| 成员变量 | 支持 | 支持 |
| 成员函数 | 不可（仅函数指针） | 可以（直接定义方法） |
| 访问控制 | 全部公有 | `public`/`private`/`protected` |
| 构造函数 | 不可（需手动初始化） | 可以 自动调用 |
| 析构函数 | 不可 | 可以 自动调用资源释放 |
| 继承 | 不可 | 可以（但本文不涉及） |
| 默认成员权限 | 公有 | 私有（`class`）/ 公有（`struct`） |

## 11. 完整示例：一个简单的栈类

```cpp
#include <iostream>   // C++ 输入输出，可用 printf 替换
using namespace std;

class IntStack {
private:
    int* data;
    int capacity;
    int top;
public:
    // 构造函数
    IntStack(int cap = 10) : capacity(cap), top(-1) {
        data = new int[capacity];
    }

    // 析构函数
    ~IntStack() {
        delete[] data;
    }

    // 成员函数
    bool push(int val) {
        if (top >= capacity - 1) return false;
        data[++top] = val;
        return true;
    }

    bool pop(int& out) {
        if (top < 0) return false;
        out = data[top--];
        return true;
    }

    bool isEmpty() const { return top == -1; }
    int size() const { return top + 1; }
};

int main() {
    IntStack stack(5);
    for (int i = 0; i < 5; ++i) stack.push(i * 10);
    int val;
    while (stack.pop(val)) {
        cout << val << " ";   // 输出 40 30 20 10 0
    }
    return 0;
}
```
