## 1. 基本概念与客观规则

运算符重载本质上是**定义一个特殊的成员函数或全局函数**，函数名为 `operator` 后跟运算符符号（如 `operator+`、`operator==`）。

**硬性规定（客观事实）**：
1. **不能发明新运算符**：只能重载 C++ 中已有的运算符（如 `+`、`-`、`*`、`/`、`%`、`^`、`&`、`|`、`~`、`!`、`=`、`<`、`>`、`+=`、`--`、`[]`、`()`、`->` 等）。
2. **不能改变优先级与结合性**：重载后 `+` 仍优先于 `==`，不影响语法解析。
3. **不能改变操作数个数**：一元运算符保持 1 个操作数，二元保持 2 个（成员函数隐含 `this` 算作左操作数）。
4. **至少一个操作数是用户定义类型**：无法重载 `int + int` 的内置行为。
5. **部分运算符不可重载**：`::`（作用域解析）、`.`（成员访问）、`.*`（成员指针访问）、`?:`（条件运算符）、`sizeof`、`typeid`。

## 2. 两种实现形式：成员函数 vs. 非成员函数

| 实现方式 | 左操作数来源 | 典型适用场景 |
|---------|-------------|-------------|
| **成员函数** | `this` 指向当前对象 | 左操作数必须是本类对象（如 `c1 + c2`） |
| **非成员函数（友元）** | 显式参数列表（第一个参数为左操作数） | 左操作数可隐式转换（如 `2 + c1`）或非本类对象（如 `cout << obj`） |

**成员函数声明**：`返回值 operator符号(参数列表);`  
**非成员函数声明**：`返回值 operator符号(左操作数类型, 右操作数类型);`

## 3. 二元运算符重载（以复数类为例）

### 3.1 `+` 运算（成员函数实现）
```cpp
class Complex {
private:
    double real, imag;
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // 成员函数：左操作数为 this，右操作数为参数
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
};

int main() {
    Complex c1(1, 2), c2(3, 4);
    Complex c3 = c1 + c2;   // 调用 c1.operator+(c2)
    return 0;
}
```

### 3.2 `==` 与 `!=` 运算（非成员函数实现，支持左右对称）
若使用成员函数，`c == 2` 可编译（若构造函数支持隐式转换），但 `2 == c` 会失败，因为 `2` 不是类对象。**非成员函数**可解决此对称性问题：
```cpp
class Complex { /* 同上 */ };

// 非成员函数（通常声明为友元以访问私有成员）
bool operator==(const Complex& lhs, const Complex& rhs) {
    return lhs.real == rhs.real && lhs.imag == rhs.imag;
}

bool operator!=(const Complex& lhs, const Complex& rhs) {
    return !(lhs == rhs);
}

int main() {
    Complex c(1, 2);
    if (c == Complex(1, 2)) { /* 通过 */ }
    if (Complex(1, 0) == 1) { /* 通过（int 隐式转 Complex） */ }
    if (1 == Complex(1, 0)) { /* 通过（非成员函数允许左操作数 int 转换） */ }
    return 0;
}
```
**注意**：为使 `1 == c` 生效，非成员函数的第一个参数 `lhs` 必须支持从 `int` 到 `Complex` 的隐式构造函数。

## 4. 一元运算符重载（`-`、`++`、`--`）

### 4.1 负号运算符 `-`（成员函数）
```cpp
class Complex {
public:
    // 返回相反数
    Complex operator-() const {
        return Complex(-real, -imag);
    }
};

int main() {
    Complex c(3, 4);
    Complex neg = -c;   // 调用 c.operator-()
}
```

### 4.2 自增 `++` 的前置与后置（重要语法区别）
C++ 通过**哑元参数 `int`** 区分前置与后置：

| 形式 | 声明（成员） | 行为 |
|------|-------------|------|
| **前置 `++c`** | `Complex& operator++()` | 先修改自身，再返回自身引用 |
| **后置 `c++`** | `Complex operator++(int)` | 先保存旧值，修改自身，返回旧值（临时对象） |

```cpp
class Counter {
private:
    int value;
public:
    Counter(int v = 0) : value(v) {}

    // 前置 ++：返回引用
    Counter& operator++() {
        ++value;
        return *this;
    }

    // 后置 ++：返回旧值（临时拷贝），哑元 int 仅用于区分
    Counter operator++(int) {
        Counter temp = *this;   // 保存当前状态
        ++value;                // 修改自身
        return temp;            // 返回旧值
    }

    int get() const { return value; }
};

int main() {
    Counter c(5);
    ++c;          // 调用 operator++()
    c++;          // 调用 operator++(0)
    return 0;
}
```

## 5. 赋值运算符 `operator=`（特殊关注点）

赋值运算符是**唯一必须被定义为成员函数**的二元运算符（若需要重载）。编译器会默认生成一个逐成员拷贝的赋值函数（浅拷贝）。若类持有动态内存资源，必须自定义深拷贝。

```cpp
class String {
private:
    char* data;
public:
    String(const char* str = "") {
        data = new char[strlen(str) + 1];
        strcpy(data, str);
    }

    // 拷贝赋值（返回引用以支持链式赋值 a = b = c）
    String& operator=(const String& other) {
        if (this == &other) return *this;   // 自赋值检测

        delete[] data;                      // 释放旧内存
        data = new char[strlen(other.data) + 1];
        strcpy(data, other.data);
        return *this;
    }

    ~String() { delete[] data; }
};
```
**关键规则**：返回值类型通常为 `类名&`，支持 `a = b = c` 的链式操作，并与内置类型行为一致。

## 6. 下标运算符 `operator[]`（容器类必备）

```cpp
class IntArray {
private:
    int* elements;
    int size;
public:
    IntArray(int n) : size(n), elements(new int[n]) {}

    // 非 const 版本：返回左值引用，允许 arr[i] = 5
    int& operator[](int index) {
        return elements[index];
    }

    // const 版本：const 对象只读访问
    const int& operator[](int index) const {
        return elements[index];
    }

    ~IntArray() { delete[] elements; }
};

int main() {
    IntArray arr(10);
    arr[0] = 100;          // 调用 int& operator[](int)
    int val = arr[0];      // 若 arr 非 const，也可调用非 const 版本
    const IntArray& carr = arr;
    int read = carr[0];    // 调用 const int& operator[](int) const
}
```

## 7. 函数调用运算符 `operator()`（仿函数）

允许对象像函数一样被调用，常用于 STL 算法（本文仅展示语法）：
```cpp
class Multiplier {
private:
    int factor;
public:
    Multiplier(int f) : factor(f) {}
    int operator()(int x) const {
        return x * factor;
    }
};

int main() {
    Multiplier times3(3);
    int result = times3(5);   // 调用 operator()(5)，返回 15
    return 0;
}
```

## 8. 输入输出流运算符 `<<` 与 `>>`（必须为非成员）

C++ 的标准库使用 `std::ostream` 和 `std::istream` 进行输入输出。左操作数是流对象（如 `std::cout`），**不能定义为成员函数**（否则调用需写成 `obj << cout`，违反直觉）。

```cpp
#include <iostream>
using namespace std;

class Point {
private:
    int x, y;
public:
    Point(int a = 0, int b = 0) : x(a), y(b) {}

    // 声明为友元以访问私有成员（也可提供 public getter）
    friend ostream& operator<<(ostream& os, const Point& p);
    friend istream& operator>>(istream& is, Point& p);
};

// 输出：os << p
ostream& operator<<(ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;   // 返回流引用以支持链式输出
}

// 输入：is >> p
istream& operator>>(istream& is, Point& p) {
    is >> p.x >> p.y;
    return is;
}

int main() {
    Point p1(3, 4);
    cout << "Point: " << p1 << endl;   // 输出 Point: (3, 4)

    Point p2;
    cout << "Enter x and y: ";
    cin >> p2;                         // 调用 operator>>
    return 0;
}
```

## 9. C 程序员必须警惕的“陷阱”（客观差异）

| 传统 C 习惯 | C++ 运算符重载后的差异 |
|------------|----------------------|
| `&&` 和 `||` 具有短路求值（左侧为假则不计算右侧） | 重载后变为普通函数调用，**失去短路特性**，两侧均会求值。实践中不建议重载。 |
| 逗号运算符 `,` 保证从左到右求值 | 重载后变为函数调用，**求值顺序不再保证**。不建议重载。 |
| 取地址 `&` 直接获取内存地址 | 重载 `operator&` 后，`&obj` 可能返回任意值，导致 `std::addressof` 需特殊处理。 |
| `new` / `delete` 为内存分配关键字（C 用 malloc） | 可重载 `operator new` 改变内存分配行为（但本文不展开）。 |
| 指针解引用 `*` 和 `->` | `operator->` 可重载（智能指针常见），返回值需是指针或支持 `->` 的对象，且会连续调用。 |

## 10. 完整可运行示例：有理数类（整合多个运算符）

```cpp
#include <iostream>
using namespace std;

class Rational {
private:
    int num, den;   // 分子/分母
    void simplify() { /* 省略约分实现，仅作展示 */ }
public:
    Rational(int n = 0, int d = 1) : num(n), den(d) { simplify(); }

    // 算术运算符（成员函数）
    Rational operator+(const Rational& other) const {
        return Rational(num * other.den + other.num * den, den * other.den);
    }

    // 比较运算符（非成员友元，支持对称）
    friend bool operator==(const Rational& lhs, const Rational& rhs) {
        return lhs.num * rhs.den == rhs.num * lhs.den;
    }

    // 前置 ++
    Rational& operator++() {
        num += den;
        return *this;
    }

    // 后置 ++
    Rational operator++(int) {
        Rational temp = *this;
        num += den;
        return temp;
    }

    // 输出流
    friend ostream& operator<<(ostream& os, const Rational& r) {
        os << r.num << "/" << r.den;
        return os;
    }
};

int main() {
    Rational r1(1, 2), r2(1, 3);
    Rational r3 = r1 + r2;
    cout << "r1 + r2 = " << r3 << endl;   // 输出 5/6

    ++r1;
    cout << "++r1 = " << r1 << endl;

    cout << "r1 == r2 ? " << (r1 == r2) << endl;
    return 0;
}
```
