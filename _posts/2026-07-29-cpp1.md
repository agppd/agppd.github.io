## 你的第一份C语言代码

```c
int main(){}
```

将它保存为`main.c`，并编译

```bash
gcc -c main.o main.c
```

连接，这里我们都使用`gcc`去处理

```bash
gcc -o main main.o
```

## 它干了什么

我们一句句分析这份代码：

`int` ：声明一个整型，至于是什么，我们接着看

`main()`：一个叫`main`的函数，这不是完整的写法，这是简写，`C`默认从`main()`函数开始执行，
其中：`()`里面是函数传参，默认为空，但是`main()`函数只有三种声明方式：

- `main()`这种简写
- `main(void)`这种表示编译出的程序命令行调用时不传参
- `main(int argc, char *argv[])`这是`main()`的全称，`argc`是一个变量，存储命令行参数数量；`argv`是一个字符串（目前这么理解就行），表示参数内容。

`{}`：函数的通用写法，必须存在（目前这么理解就行，后面会在编译的处理讲到）
