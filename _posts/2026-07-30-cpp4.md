## 分支语句

在程序设计中，分支语句（又称选择结构）允许程序根据条件的不同执行不同的代码路径。C语言提供了两种主要的分支结构：`if` 语句和 `switch` 语句。

### if 语句

`if` 语句是最基本的条件判断结构，其语法形式如下：

```c
if (条件表达式) {
    /* 条件为真时执行的语句 */
}
```

当条件表达式的值为非零（即“真”）时，执行花括号内的代码块；若为零（“假”），则跳过。

#### if-else 结构

若需要在条件为假时执行另一段代码，可使用 `if-else`：

```c
if (条件) {
    /* 真分支 */
} else {
    /* 假分支 */
}
```

#### 多重 if-else if

当有多个互斥条件时，可以串联多个 `else if`：

```c
if (条件1) {
    /* 条件1为真 */
} else if (条件2) {
    /* 条件1为假且条件2为真 */
} else {
    /* 所有条件均为假 */
}
```

**注意**：在 C89 标准（即 ANSI C）中，变量的声明必须放在代码块的最前面，不能混在语句中间。例如：

```c
/* 正确：声明在前 */
int score;
scanf("%d", &score);

if (score >= 90) {
    int grade = 'A';  /* C89允许在块内声明，但必须位于块开头 */
    printf("等级：%c\n", grade);
}
```

但更推荐将所有变量声明在函数开头，以增强可读性。

#### 嵌套 if

`if` 语句可以嵌套使用，但要注意 `else` 的匹配问题——`else` 总是与最近的未配对 `if` 结合。建议使用花括号明确层级。

### switch 语句

当需要根据一个整型表达式的值跳转到多个分支时，`switch` 比多个 `if-else` 更清晰：

```c
switch (整型表达式) {
    case 常量1:
        /* 语句 */
        break;
    case 常量2:
        /* 语句 */
        break;
    default:
        /* 所有 case 都不匹配时执行 */
        break;
}
```

- `case` 后面的值必须是整型常量（字符常量也可，因其本质是整数）。
- `break` 用于跳出 `switch` 结构，若省略则会“穿透”到下一个 `case`（即继续执行后续代码），这有时被故意利用，但多数情况需谨慎。
- `default` 分支可选，通常放在最后。

示例：根据数字输出星期几。

```c
int day = 3;
switch (day) {
    case 1: printf("Monday\n"); break;
    case 2: printf("Tuesday\n"); break;
    case 3: printf("Wednesday\n"); break;
    default: printf("Invalid day\n"); break;
}
```

## 循环语句

循环结构允许程序重复执行一段代码，直到满足退出条件。C语言提供三种循环：`while`、`do-while` 和 `for`。

### while 循环

```c
while (条件) {
    /* 循环体 */
}
```

先判断条件，若为真则执行循环体，执行完后再次判断，直至条件为假。如果初始条件为假，循环体一次也不执行。

### do-while 循环

```c
do {
    /* 循环体 */
} while (条件);
```

先执行一次循环体，再判断条件，若为真则继续执行。因此，`do-while` 至少执行一次，适用于需要至少执行一次的场景（如菜单输入）。

### for 循环

`for` 循环将初始化、条件判断和迭代集中在一行，语法如下：

```c
for (初始化表达式; 条件表达式; 迭代表达式) {
    /* 循环体 */
}
```

执行顺序：
1. 执行初始化表达式（通常用于设置循环变量）。
2. 判断条件，若为假则跳出循环。
3. 若为真，执行循环体。
4. 执行迭代表达式（通常用于改变循环变量）。
5. 回到步骤2。

例如，打印 1 到 10：

```c
int i;
for (i = 1; i <= 10; i++) {
    printf("%d ", i);
}
```

### 循环控制语句

- `break`：立即终止当前所在的最内层循环（或 `switch`），跳出循环体。
- `continue`：跳过本次循环体剩余的语句，直接进入下一次迭代（对于 `for`，会先执行迭代表达式，再判断条件）。

### 嵌套循环

循环可以嵌套，例如打印乘法表：

```c
int i, j;
for (i = 1; i <= 9; i++) {
    for (j = 1; j <= i; j++) {
        printf("%d*%d=%-2d ", j, i, i * j);
    }
    printf("\n");
}
```
