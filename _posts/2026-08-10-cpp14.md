## 1. 多态的分类（客观定义）

在 C++ 标准中，多态主要分为两类：

| 类型 | 绑定时机 | 实现手段 | C 语言对应 |
|------|----------|----------|------------|
| **编译期多态（静态多态）** | 编译时 | 函数重载、运算符重载、模板 | 宏、`_Generic`（C11）、函数指针作为参数 |
| **运行期多态（动态多态）** | 运行时 | `virtual` 函数 + 继承 | 结构体中的函数指针 + 手动赋值 |

> 本文重点讲解 **运行期多态**，因为这是 C 程序员迁移到 C++ 时最需要理解的新机制。

---

## 2. 运行期多态的核心语法

运行期多态依赖三个基本要素：
1. **公有继承**（`public` 派生）。
2. **基类中的虚函数**（`virtual` 关键字）。
3. **通过基类指针或引用**调用虚函数。

### 2.1 基本示例

```cpp
#include <iostream>
using namespace std;

class Animal {
public:
    // 虚函数：声明为 virtual，允许派生类覆盖（override）
    virtual void speak() const {
        cout << "Animal makes a sound." << endl;
    }

    // 虚析构函数（后面会专门讲为什么必须加）
    virtual ~Animal() {}
};

class Dog : public Animal {
public:
    // override 关键字（C++11 起）显式标注覆盖，非强制但强烈推荐
    void speak() const override {
        cout << "Dog barks: Woof!" << endl;
    }
};

class Cat : public Animal {
public:
    void speak() const override {
        cout << "Cat meows: Meow!" << endl;
    }
};

// 全局函数接受基类引用，实现多态
void makeSound(const Animal& animal) {
    animal.speak();   // 运行时决定调用哪个版本
}

int main() {
    Dog dog;
    Cat cat;

    makeSound(dog);   // 输出: Dog barks: Woof!
    makeSound(cat);   // 输出: Cat meows: Meow!

    Animal* ptr = new Dog();
    ptr->speak();     // 输出: Dog barks: Woof!
    delete ptr;

    return 0;
}
```

### 2.2 关键规则
- **覆盖（Override）**：派生类中重新定义的虚函数，**函数签名（参数列表、const 修饰）必须与基类完全一致**，否则是“隐藏”（Hide）而非覆盖，无法实现多态。
- **`override` 关键字（C++11）**：写在派生类函数末尾，如果并未正确覆盖基类虚函数，编译器会报错，避免手误。

## 3. 底层实现机制

C++ 运行时多态并非魔法，其底层实现与 C 语言中用**结构体存储函数指针**异曲同工。标准未规定具体实现，但几乎所有编译器（GCC、Clang、MSVC）都采用 **VTable（虚函数表）** + **VPtr（虚指针）** 模型。

### 3.1 内存布局
1. **每个含有虚函数的类**（或从含有虚函数的类派生），编译器为其生成一个 **VTable**（虚函数表）——这是一个**函数指针数组**，存储该类所有虚函数的地址。
2. **每个对象实例**在其内存起始位置（或特定偏移处）隐含一个 **VPtr**（`void**`），指向该类对应的 VTable。
3. 调用虚函数时，编译器生成代码：**通过对象的 VPtr 找到 VTable，再从 VTable 中取出对应函数指针，然后跳转执行**。

### 3.2 静态类型 vs. 动态类型
- **静态类型（Static Type）**：变量声明时的类型（如 `Animal* ptr`）。
- **动态类型（Dynamic Type）**：指针或引用实际指向对象的类型（如 `Dog`）。
- 对于非虚函数，调用取决于静态类型；对于虚函数，调用取决于动态类型。

### 3.3 C 语言模拟 VTable（理解本质）

以下 C 代码模拟了 C++ 虚函数机制的核心逻辑：

```c
#include <stdio.h>
#include <stdlib.h>

// 1. 定义虚函数表结构（相当于 C++ 的 VTable）
struct AnimalVTable {
    void (*speak)(void* self);  // 函数指针，self 相当于 this
    void (*destroy)(void* self);
};

// 2. 定义基类结构（包含 VPtr）
struct Animal {
    struct AnimalVTable* vptr;  // 虚指针
    // ... 其他成员
};

// 3. 基类函数实现
void Animal_speak(void* self) {
    printf("Animal makes a sound.\n");
}
void Animal_destroy(void* self) {
    free(self);
}
// 基类 VTable（全局静态数据）
struct AnimalVTable g_AnimalVTable = { Animal_speak, Animal_destroy };

// 4. 基类构造函数（初始化 VPtr）
void Animal_ctor(struct Animal* this) {
    this->vptr = &g_AnimalVTable;
}

// 5. 派生类 Dog
struct Dog {
    struct Animal base;  // 继承基类（VPtr 位于最前面）
    // 额外成员...
};

void Dog_speak(void* self) {
    printf("Dog barks: Woof!\n");
}
// 派生类 VTable（覆盖了 speak 指针）
struct AnimalVTable g_DogVTable = { Dog_speak, Animal_destroy };

void Dog_ctor(struct Dog* this) {
    Animal_ctor(&this->base);       // 先构造基类
    this->base.vptr = &g_DogVTable; // 关键：将 VPtr 指向派生类 VTable
}

// 6. 多态函数（类似于接受基类指针）
void makeSound(struct Animal* animal) {
    animal->vptr->speak(animal);  // 通过 VPtr 间接调用
}

int main() {
    struct Dog* dog = malloc(sizeof(struct Dog));
    Dog_ctor(dog);
    makeSound((struct Animal*)dog); // 输出: Dog barks: Woof!
    dog->base.vptr->destroy(dog);
    return 0;
}
```

> **客观结论**：C++ 的虚函数本质上是将 C 语言中“手动维护函数指针”的工作**交由编译器自动化**，并增加了类型安全检查。理解了上述 C 代码，你就理解了 C++ 多态的全部底层基础。

## 4. 抽象类与纯虚函数（Pure Virtual Function）

当基类中的某个函数无法给出有意义的实现时，可将其声明为**纯虚函数（Pure Virtual Function）**，语法是在函数声明末尾加 `= 0`。

### 4.1 语法与效果
- **含有纯虚函数的类称为抽象类（Abstract Class）**，无法实例化对象。
- 派生类必须覆盖所有纯虚函数，否则派生类依然是抽象类。

```cpp
class Shape {
public:
    // 纯虚函数：此处无实现，要求子类必须实现
    virtual double area() const = 0;

    // 普通虚函数可以有默认实现
    virtual void description() const {
        cout << "This is a shape." << endl;
    }

    virtual ~Shape() {}
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    // 必须实现纯虚函数
    double area() const override {
        return 3.14159 * radius * radius;
    }
};

int main() {
    // Shape s;            // 错误！抽象类不能实例化
    Circle c(5.0);         // 正确
    Shape* p = &c;
    cout << p->area();     // 输出 78.53975
    return 0;
}
```

### 4.2 接口概念
**纯虚类**在 C++ 中常用来定义**接口（Interface）**，类似于 Java 的 `interface` 或 C# 的 `interface`，仅声明方法而不提供实现。

## 5. 虚析构函数（必须掌握的关键点）

**规则**：若一个类被用作基类，且你通过基类指针 `delete` 派生类对象，则**基类析构函数必须声明为 `virtual`**。否则仅执行基类析构，派生类资源无法释放，造成内存泄漏。

```cpp
class Base {
public:
    ~Base() { cout << "Base destructor" << endl; }  // 非虚
};

class Derived : public Base {
private:
    int* data;
public:
    Derived() { data = new int[100]; }
    ~Derived() { delete[] data; cout << "Derived destructor" << endl; }
};

int main() {
    Base* p = new Derived();
    delete p;   // 仅调用 Base::~Base()！Derived::~Derived() 未执行 -> 内存泄漏
}
```
**修复**：将基类析构声明为 `virtual`：
```cpp
class Base {
public:
    virtual ~Base() { cout << "Base destructor" << endl; }
};
// 此时 delete p 会先调用 Derived::~Derived，再调用 Base::~Base
```

## 6. 动态绑定的限制与陷阱（客观难点）

### 6.1 对象切片（Object Slicing）
当派生类对象按值赋值给基类对象时，派生类特有部分被“切掉”，**多态失效**。
```cpp
Dog dog;
Animal animal = dog;   // 切片！仅复制 Animal 部分，vptr 指向 Animal 的 VTable
animal.speak();        // 输出 Animal 版本，而非 Dog 版本（静态绑定）
```

### 6.2 构造函数与析构函数中调用虚函数
在构造函数或析构函数内部，**虚函数机制不按预期工作**。此时对象的动态类型被视为当前正在构造/析构的类本身，而非最终派生类。
```cpp
class Base {
public:
    Base() { print(); }  // 调用的 print 是 Base 版本
    virtual void print() { cout << "Base"; }
};

class Derived : public Base {
public:
    void print() override { cout << "Derived"; }
};

Derived d;  // 输出 "Base"，而非 "Derived"
```
**原因**：构造时先构造基类，此时派生类尚未初始化完成，VPtr 指向基类 VTable；析构时同理，派生类先析构，VPtr 被改回基类 VTable。

### 6.3 隐藏（Hiding）而非覆盖（Override）
如果派生类中定义了一个与基类虚函数**同名但参数不同**的函数，它不会覆盖基类函数，而是**隐藏**基类所有同名函数。
```cpp
class Base {
public:
    virtual void func(int x) {}
};
class Derived : public Base {
public:
    virtual void func(double x) {}  // 参数不同，隐藏而非覆盖！
};
Derived d;
// d.func(10);    // 错误！int 无法匹配 double? 实际上是 int 被隐藏，找不到 Base::func(int)
```
**解决**：使用 `using Base::func;` 或确保参数列表一致，并加 `override` 捕获此类错误。

### 6.4 默认参数与虚函数（极度隐蔽）
虚函数的**默认参数值（Default Arguments）** 在编译期根据**静态类型**决定，而非动态类型。
```cpp
class Base {
public:
    virtual void show(int val = 10) { cout << "Base: " << val; }
};
class Derived : public Base {
public:
    void show(int val = 20) override { cout << "Derived: " << val; }
};

Base* p = new Derived();
p->show();  // 输出 "Derived: 10" （动态类型调用 Derived::show，但默认参数使用 Base 的 10）
```
**建议**：**永远不要给虚函数设置默认参数**，或者采用非虚接口（NVI）模式规避。

## 7. 多态下的访问权限控制

- 虚函数可以是 `private`，但仍可实现多态（通过基类公共非虚函数调用私有虚函数，即 NVI 惯用法）。
- 派生类覆盖基类虚函数时，派生类的访问权限可以改变（可以扩大，但不能缩小？客观事实是 C++ 允许派生类将覆盖函数设置为不同访问级别，但这会破坏基类契约，不推荐）。

## 8. 运行期类型识别（RTTI）

C++ 通过 `typeid` 和 `dynamic_cast` 提供运行期类型信息，前提是类拥有至少一个虚函数。

### 8.1 `typeid` 运算符
```cpp
#include <typeinfo>
Animal* p = new Dog();
if (typeid(*p) == typeid(Dog)) {
    cout << "It's a Dog!" << endl;
}
```
**注意**：若 `p` 为 `nullptr`，`typeid(*p)` 会抛出 `std::bad_typeid` 异常。

### 8.2 `dynamic_cast` 安全向下转型
```cpp
Base* basePtr = new Derived();
Derived* derivedPtr = dynamic_cast<Derived*>(basePtr);
if (derivedPtr) {
    // 转型成功，调用派生类特有方法
}
```
若转型失败（如指向对象非目标类型），返回 `nullptr`（指针版本）或抛出 `std::bad_cast`（引用版本）。
