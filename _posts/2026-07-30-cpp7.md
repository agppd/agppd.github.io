**在 ANSI C中，不存在结构体里编写函数的写法**

## 一、结构体的定义与声明

### 1.1 定义结构体类型

结构体类型的定义使用关键字 `struct`，后跟一个可选的**标签（tag）**，然后在大括号中列出成员（字段），每个成员都有自己的类型和名称。

```c
struct Student {
    int id;
    char name[20];
    int age;
    float score;
};
```

以上定义了一个名为 `struct Student` 的新数据类型，它包含四个成员：`id`（整型）、`name`（字符数组，用于存储姓名）、`age`（整型）、`score`（浮点型）。注意：这只是一个**类型定义**，并没有分配任何内存空间，只是告诉编译器这种类型长什么样子。

### 1.2 声明结构体变量

定义好类型后，我们可以像使用 `int` 一样声明变量。

```c
struct Student stu1;          /* 声明一个 struct Student 类型的变量 */
struct Student stu2, stu3;    /* 同时声明多个 */
```

也可以在定义类型的同时声明变量：

```c
struct Point {
    int x;
    int y;
} p1, p2;                     /* 定义了类型 struct Point，并声明了 p1、p2 两个变量 */
```

如果不再需要这个类型标签（后续不再使用），可以省略标签（匿名结构体），但通常不建议，因为后续无法再用该类型声明其他变量。

### 1.3 使用 `typedef` 简化类型名称

为了书写方便，常用 `typedef` 为结构体类型起一个别名。

```c
typedef struct {
    int x;
    int y;
} Point;                      /* 现在 Point 就是类型名，无需再写 struct Point */

Point p1, p2;                 /* 直接使用别名 */
```

或者保留标签并加上别名：

```c
typedef struct Student {
    int id;
    char name[20];
    int age;
    float score;
} Student;                    /* 现在 Student 和 struct Student 均可使用 */
```

## 二、结构体变量的初始化与访问

### 2.1 初始化

结构体变量可以在声明时进行初始化，使用大括号按成员顺序提供初值。

```c
struct Student stu1 = {1001, "Alice", 20, 95.5};
```

也可以指定成员名进行初始化（C99及以后支持，ANSI C89 不支持指定初始化，但这里我们遵循 ANSI C，所以使用顺序初始化）。

对于嵌套结构体，可以嵌套使用大括号。

### 2.2 访问成员——点运算符

使用 `.` 运算符（成员访问运算符）来访问结构体变量的各个成员。

```c
struct Student stu;
stu.id = 1002;
stu.age = 21;
/* stu.name 是一个字符数组，可以分别给每个元素赋值 */
stu.name[0] = 'B';
stu.name[1] = 'o';
stu.name[2] = 'b';
stu.name[3] = '\0';   /* 确保字符串结束 */
stu.score = 88.0;
```

成员变量可以像普通变量一样参与运算。

### 2.3 结构体的整体赋值

同类型的结构体变量之间可以直接赋值（整体拷贝），这会逐成员复制所有内容。

```c
struct Student stu1 = {1001, "Alice", 20, 95.5};
struct Student stu2;
stu2 = stu1;   /* 将 stu1 的所有成员值复制给 stu2 */
```

注意：如果成员包含指针，则复制的是指针值（地址），而不是指向的数据，这称为**浅拷贝**，后续在指针成员时会特别说明。

## 三、结构体与数组

### 3.1 结构体数组

我们可以声明一个结构体数组，每个元素都是一个结构体变量。

```c
struct Student class[30];    /* 一个包含 30 个学生的数组 */
class[0].id = 1;             /* 访问第一个学生的 id */
class[1].age = 22;           /* 访问第二个学生的 age */
```

初始化结构体数组与普通数组类似，每个元素用大括号括起来。

```c
struct Student class[3] = {
    {1001, "Alice", 20, 95.5},
    {1002, "Bob", 21, 88.0},
    {1003, "Charlie", 19, 92.5}
};
```

### 3.2 结构体中的数组成员

结构体的成员可以是数组（如上面的 `char name[20]`）。访问数组成员时，可以像普通数组一样使用下标。

```c
struct Student stu;
stu.name[0] = 'J';
stu.name[1] = 'o';
/* ... */
```

## 四、结构体与指针

指向结构体的指针非常常用，尤其是在动态数据结构（如链表）中。

### 4.1 指向结构体的指针

```c
struct Student stu = {1001, "Alice", 20, 95.5};
struct Student *p = &stu;     /* p 指向 stu */
```

### 4.2 通过指针访问成员——箭头运算符

如果通过指针访问结构体的成员，有两种方式：先解引用再使用点运算符，或者使用箭头运算符 `->`（更常用）。

```c
(*p).id = 1003;   /* 解引用后使用点运算符 */
p->age = 22;      /* 箭头运算符，更简洁 */
```

`p->age` 等价于 `(*p).age`，但书写更方便。

### 4.3 结构体指针作为函数参数

当需要修改结构体变量的内容，或者传递较大的结构体以避免拷贝开销时，通常传递指向结构体的指针。

```c
void set_student_id(struct Student *p, int new_id) {
    p->id = new_id;   /* 修改原始结构体的成员 */
}

void init_student(struct Student *p, int id, const char *name, int age, float score) {
    p->id = id;
    /* 手动复制 name 的每个字符，因为没有字符串函数可用 */
    int i = 0;
    while (name[i] != '\0') {
        p->name[i] = name[i];
        i++;
    }
    p->name[i] = '\0';
    p->age = age;
    p->score = score;
}

/* 使用示例（在 main 中） */
struct Student stu;
init_student(&stu, 2001, "David", 23, 82.5);
```

这种方式避免了结构体的值拷贝，提高了效率，且可以修改原结构体。

### 4.4 结构体成员为指针

结构体的成员可以是指针，这常用于动态分配的字符串或链式结构。

```c
struct Person {
    char *name;    /* 指向字符的指针，可能指向动态分配的字符串 */
    int age;
};
```

当结构体包含指针成员时，整体赋值（浅拷贝）会复制指针值，但不会复制指针指向的数据。如果两个结构体共享同一块动态内存，修改一个会影响另一个，需要特别注意。

## 五、结构体的嵌套

结构体可以嵌套，即一个结构体的成员是另一个结构体类型。

```c
struct Date {
    int year;
    int month;
    int day;
};

struct Student {
    int id;
    char name[20];
    struct Date birthday;   /* 嵌套结构体 */
    float score;
};
```

访问嵌套成员时，使用多个点运算符。

```c
struct Student stu;
stu.birthday.year = 2000;
stu.birthday.month = 5;
stu.birthday.day = 15;
```

也可以声明嵌套结构体的变量并初始化：

```c
struct Student stu = {1001, "Alice", {2000, 5, 15}, 95.5};
```

## 六、结构体的自引用

结构体可以包含指向自身类型的指针，这是构造链表、树等动态数据结构的基础。

```c
struct ListNode {
    int data;
    struct ListNode *next;   /* 指向下一个同类型节点的指针 */
};
```

注意：不能包含自身类型的非指针成员（如 `struct ListNode next;`），因为那样会导致无限递归，无法确定大小。但可以包含指针，因为指针的大小是固定的。

使用自引用结构体，我们可以构建简单的链表（但这里不涉及动态内存分配，仅展示定义）。

```c
struct ListNode node1, node2;
node1.data = 10;
node2.data = 20;
node1.next = &node2;   /* 链接 node1 到 node2 */
node2.next = 0;        /* 空指针表示链表结束 */
```

## 七、结构体的内存对齐与大小

### 7.1 内存对齐

结构体在内存中的布局并非简单地将成员依次排列。为了提高访问效率，编译器会在成员之间插入**填充字节（padding）**，使得每个成员的起始地址对齐到其类型大小的整数倍。

```c
struct Example {
    char c;        /* 1 字节 */
    int i;         /* 4 字节 */
};
```

在典型的32位系统中，`char` 占1字节，`int` 占4字节，但整个结构体的大小可能是8字节而不是5字节。因为 `int` 需要对齐到4字节边界，所以编译器在 `c` 后面填充了3个字节，使得 `i` 从地址偏移4处开始。

### 7.2 计算结构体大小

可以使用 `sizeof` 运算符获取结构体的大小（包括填充）。

```c
size_t size = sizeof(struct Student);   /* 返回整个结构体占用的字节数 */
```

不同平台上填充规则可能不同，因此结构体大小依赖于编译器和目标架构。为了减少填充，可以将成员按从大到小的顺序排列（通常按类型大小降序），以紧凑布局。

### 7.3 偏移量（offsetof）

虽然ANSI C没有提供直接的宏，但可以通过一些技巧获取成员相对于结构体起始地址的偏移量（通常用 `offsetof` 宏在 `<stddef.h>` 中定义，但我们不使用库，仅作概念说明）。理解偏移有助于指针操作，例如通过基地址和偏移量访问成员。

## 八、结构体与函数

### 8.1 结构体作为返回值

函数可以返回结构体类型。返回值是结构体的一个副本（深拷贝对于非指针成员）。

```c
struct Student create_student(int id, const char *name, int age, float score) {
    struct Student s;
    s.id = id;
    /* 手动复制 name */
    int i = 0;
    while (name[i] != '\0') {
        s.name[i] = name[i];
        i++;
    }
    s.name[i] = '\0';
    s.age = age;
    s.score = score;
    return s;
}
```

### 8.2 结构体作为参数

传结构体给函数时，默认是值传递，即拷贝整个结构体。对于大型结构体，效率较低，通常传递指针。

```c
/* 值传递（拷贝） */
void print_student(struct Student s) { /* 只读访问，不修改 */ }

/* 指针传递（推荐） */
void modify_student(struct Student *p) { p->age++; }
```

### 8.3 指向结构体的指针作为参数和返回值

函数也可以返回指向结构体的指针，但必须确保指针指向的内存是有效的（如静态变量、全局变量或动态分配的内存，不能返回局部变量的地址）。

```c
struct Student* get_student(void) {
    static struct Student s = {1001, "Static", 30, 90.0};
    return &s;   /* 静态变量生命周期贯穿整个程序，安全 */
}
```

## 九、结构体与联合体、枚举的简单对比

虽然本讲主题是结构体，但为了完整，简单提及：

- **联合体（union）**：所有成员共享同一块内存，大小等于最大成员的大小。一次只能使用其中一个成员，常用于节省空间或类型双关。
- **枚举（enum）**：定义一组命名的整数常量，用于增强代码可读性。

结构体与联合体可以嵌套使用，例如在结构中包含联合体成员。

## 十、实践建议与常见陷阱

1. **避免返回局部结构体的地址**：局部变量在函数返回后销毁，返回其指针会导致野指针。
2. **注意成员对齐**：如果对内存占用敏感（如嵌入式系统），可以调整成员顺序或使用编译器特定指令（如 `#pragma pack`）来压缩对齐，但会降低访问速度。
3. **初始化时注意数组成员**：对于字符数组成员，确保留有结束符 `'\0'` 的空间。
4. **结构体赋值时警惕指针成员**：浅拷贝可能导致多个结构体共享同一数据，修改时互相影响，需要自行实现深拷贝。
5. **使用 `const` 保护参数**：如果函数只读访问结构体，参数可以声明为 `const struct Student *p`，既安全又表达意图。
