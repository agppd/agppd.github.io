## 前情提要

C 语言中，逻辑关系与逻辑运算通过**关系运算符**和**逻辑运算符**表达

我们统一使用 `int` 类型来表示逻辑值

- **0** 表示“假”（false）
- **非 0**（通常为 1）表示“真”（true）

所有逻辑运算的结果均为 `int` 类型，且结果值严格限定为 `0` 或 `1`。

## 关系运算符

关系运算符用于比较两个操作数的大小或相等关系，返回一个整型逻辑值。

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |

```c
int a = 5;
int b = 3;
int result;

result = a > b;   /* result = 1（真） */
result = a == b;  /* result = 0（假） */
```

> **注意**：关系运算符的优先级低于算术运算符（`+`、`-`、`*` 等），因此 `a + b > c` 等价于 `(a + b) > c`。

## 逻辑运算符

逻辑运算符用于组合多个逻辑表达式，或对逻辑值取反。

| 运算符 | 名称 | 含义 | 示例 |
|--------|------|------|------|
| `&&` | 逻辑与（AND） | 两操作数均为真时结果为真 | `a > 0 && a < 10` |
| `||` | 逻辑或（OR） | 至少一个操作数为真时结果为真 | `a == 0 || b == 0` |
| `!` | 逻辑非（NOT） | 将操作数取反：真变假，假变真 | `!(a == 0)` |

**真值表（操作数以 0/非0 表示，结果以 0/1 表示）：**

| x | y | `x && y` | `x \|\| y` | `!x` |
|---|---|----------|------------|------|
| 非0 | 非0 | 1 | 1 | 0 |
| 非0 | 0 | 0 | 1 | 0 |
| 0 | 非0 | 0 | 1 | 1 |
| 0 | 0 | 0 | 0 | 1 |

**示例：**
```c
int age = 25;
int score = 85;

/* 判断年龄在 18~30 之间且分数大于 80 */
int eligible = (age >= 18 && age <= 30) && (score > 80);
/* eligible = 1 */
/* 反正我喜欢这么写 */
```
## 短路求值

C 规定 `&&` 与 `||` 运算符遵循**短路求值**规则，即仅当左侧操作数无法确定整个表达式结果时，才计算右侧操作数。

- 对于 `a && b`：若 `a` 为 0（假），则整个表达式必为 0，**不再计算 `b`**。
- 对于 `a || b`：若 `a` 为非 0（真），则整个表达式必为 1，**不再计算 `b`**。

这一特性在实际编程中常用于安全的条件防护：

```c
int *ptr = NULL;
/* 先判断 ptr 非空，再解引用，利用短路特性避免空指针访问 */
if (ptr != NULL && *ptr == 10) {
    /* 只有当 ptr 非空时，*ptr 才会被求值 */
}
```

## 运算符优先级与结合性

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 2（高） | `!` | 从右至左 | 逻辑非（一元运算符） |
| 6 | `<`、`>`、`<=`、`>=` | 从左至右 | 关系运算符 |
| 7 | `==`、`!=` | 从左至右 | 关系运算符（相等性） |
| 11 | `&&` | 从左至右 | 逻辑与 |
| 12 | `||` | 从左至右 | 逻辑或 |
| 14（低） | `=` 及复合赋值 | 从右至左 | 赋值运算符 |

## 常见错误与注意事项

### 1. 误将赋值 `=` 当作相等 `==`

这是 C 语言初学者最常犯的错误。`if (a = 5)` 在语法上完全合法——它将 5 赋给 `a`，然后判断 `a` 是否为真（非 0），因此条件永远为真。绝大多数情况下本意是 `if (a == 5)`。

```c
int a = 3;
if (a = 5) {        /* 实际为赋值操作，a 变为 5，条件恒为真 */
    /* 此块总会执行 */
}
```

为规避此类错误，可将常量置于左侧：`if (5 == a)`。若误写为 `if (5 = a)`，编译器会直接报错（无法给常量赋值）。

### 2. 浮点数直接比较的精度问题

由于浮点数（`float` / `double`）存在舍入误差，直接使用 `==` 或 `!=` 比较两个浮点数几乎总是不可靠的。正确做法是判断两者差的绝对值是否小于一个极小阈值（如 `1e-6`）。

```c
double x = 0.1 + 0.2;
double y = 0.3;

/* 不推荐：if (x == y) 通常为假 */
/* 推荐做法：比较差值是否在容差范围内 */
if (x - y < 0.000001 && x - y > -0.000001) {
    /* 认为 x 与 y 相等 */
}
```

### 3. C89 中逻辑值的“真”不唯一

在条件判断（`if`、`while` 等）中，C 将**任何非零值**视为“真”，但逻辑运算符（`&&`、`||`、`!`）的返回值**只有 `0` 或 `1`**。这意味着：
- `!10` 的结果为 `0`。
- `!!10` 的结果为 `1`（常用于将任意整数规范化为 0 或 1）。
